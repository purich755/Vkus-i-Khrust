# «Вкус и Хруст» — демо главной страницы

Кулинарный маркет, Казань, ул. Восстания, 87. Концепция «Слой за слоем»: ламинация секций, «срез» из неровных линий, золотая нить, которая в подвале замыкается в знак логотипа, и заголовки, которые «хрустят» по оси SHRP шрифта Geologica.

Статика без сборщика: `index.html`, `css/`, `js/` (Lenis + GSAP/ScrollTrigger с jsDelivr), `assets/`.
`index.html` собирается из `src/index.src.html` (`node tools/build-html.mjs` разворачивает `{{img …}}` в `<img srcset>` с реальными размерами).

```
node tools/serve.mjs 8287          # локально
node tools/shots.mjs 1440          # снимки всех разделов + переполнение по X
node tools/interact.mjs 390        # интерактив реальными событиями (статус, меню, калькулятор, иней, лайтбокс)
```

Деплой: GitHub Pages через Actions (`.github/workflows/pages.yml`). Для Vercel лежит `vercel.json`, но `*.vercel.app` в РФ открывается не у всех.

## Отклонения от ТЗ
- **Карта:** вместо iframe Яндекс.Карт — статичная тёмная схема квартала из OpenStreetMap + кнопка «Построить маршрут». Виджет Яндекса показывает звёзды рейтинга (с org) или рекламный блок (без org) — оба варианта противоречат ТЗ.
- **Логотип:** в карточке Яндекса знак — жёлтая петля на светлом круге. По ТЗ сделан тёмный круг с жёлтой петлёй; надпись «ТУТ ПЕКУТ СЧАСТЬЕ» с логотипа на сайт не выносил.
- **Жёлтый:** `--yolk: #FBBD2E` — снят пипеткой с петли логотипа.
